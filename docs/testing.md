# Testing

After installing Frida Manager and the Magisk module:

1. Open Frida Manager.
2. Press **Test Android Bridge**.
3. Press **Check Status**.
4. Press **Start Frida**.
5. Confirm the status shows `running (PID)`.
6. Press **Stop Frida**.
7. Confirm the status shows `stopped`.

The bridge test confirms communication between the React application and the native Android plugin.
